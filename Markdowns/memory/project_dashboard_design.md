Dashboard should be clean, minimalistic, and dark mode. Keep clutter low — avoid unnecessary decorations, borders, or UI chrome. Dark backgrounds, light text, subtle accents. Reference the lux curve tuner (mira_lux_curve_tuner_v5.html) as a style baseline — hidden scrollbars, restrained color use, system fonts.

**Why:** User explicitly called this out as the aesthetic direction for the dashboard.
**How to apply:** When building any dashboard UI, default to dark-mode-first, minimal components, no visual noise. Avoid light themes, heavy card shadows, or busy layouts unless asked.
